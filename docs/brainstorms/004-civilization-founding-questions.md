# 通过哲学问题生成文明基础属性

状态：初步想法，问题、属性与数值待打磨。

## 核心想法

开局之前问玩家一系列哲学问题，根据所选答案，生成文明的一些基础属性。

玩家通过回答“我们相信什么、如何生活、愿意付出什么代价”，逐步定义文明的起点。问答可以呈现为建国之前的部落议事，让文明属性带有共同历史与价值选择的意味。

## 问题设计

用具体处境承载哲学分歧，让每个答案都有吸引力和代价，避免明显的正确答案。以下效果仅为机制方向，不代表确定数值。

| 问题 | 选择方向 | 可能对应的起始倾向 |
| --- | --- | --- |
| 粮食只够度过这个冬天，族人应如何行动？ | 节制并储备 / 冒险寻找新食物 / 与邻部交换 | 储存与稳定 / 探索与风险收益 / 贸易与互惠 |
| 当祖先的经验与眼前的发现冲突时，我们相信什么？ | 延续传统 / 验证新知 | 既有生产体系的效率 / 科研与改造能力 |
| 丰收后的剩余粮食应当用在哪里？ | 公共粮仓 / 分给各家 / 举行共同祭典 | 抗灾储备 / 分散生产 / 文化与凝聚力 |
| 陌生人来到聚落边界，我们首先做什么？ | 设防观察 / 接待交换 / 派人追寻其来路 | 防御 / 贸易 / 探索 |
| 谁应决定部落的重要事务？ | 长者 / 众人议事 / 临时推举能人 | 传统延续 / 协作 / 应变 |

## 从答案到玩法

- 多道题共同影响若干倾向，避免一道题直接决定文明类型。
- 第一版可以只设置三组倾向：稳定与冒险、传统与求新、自给与交流。它们是设计用的抽象维度，不必把所有理念都压成互斥数轴。
- 最终生成少量、清晰的开局差异，例如一个文明特性、几张起始牌和一个起始建筑或建筑选项。
- 优先让差异改变玩法，而不只是增加小幅百分比：储粮倾向允许保留部分食物，探索倾向改变探索奖励，交流倾向提供起始交换手段。
- 所有组合应有可用的起步方式；倾向分散可以形成混合路线，不应成为没有奖励的错误答案。

## 与资源加工链结合

相同的资源卡，可以因文明的起始理念获得不同的加工方向：

- 重视储备：肉类或谷物结算 → 加工 → 留存部分收益，帮助跨回合稳定供给。
- 重视共同仪式：大份食物结算 → 达到门槛 → 触发祭典，获得文化。
- 重视交流：资源结算 → 形成可交换的剩余 → 支持贸易收益。

问答由此为最初的构筑提供方向，后续仍由玩家选择建筑和卡牌完善 combo。

## 与种田、航海文明结合

自然环境决定资源条件，问答决定文明面对这些条件时的初始选择。两者共同塑造开局。

例如，资源稀缺的海岸文明可以选择贸易、探索或掠夺；适合耕种的文明也可以选择向外扩张。保留环境压力，同时允许玩家形成不同的应对方式。

## 体验与待验证问题

- 第一版可先尝试 3—5 道题，控制开局时长。
- 回答结束后展示“建国理念”摘要，并清楚解释每个实际效果由哪些选择产生，允许返回修改。
- 提供快速开局、复用上次答案或预设理念，减少多次开局的重复负担。
- 理念定义起点，后续可通过事件或改革演变，避免一次问答锁死整局路线。
- 需要验证玩家是否能理解答案与效果的联系，以及是否存在一套明显最强的答案。
- 需要决定选项当场展示多少机制信息：可以用简短倾向提示保留代入感，最终确认时完整展示效果。
