# 食物流派

## 陷阱类型
### 兔子
- 过牌流
- 1锤设置一个兔子陷阱，洗入一张0锤7肉

### 食草动物陷阱
- 陷阱类型
- 0锤设置一个食草动物陷阱，洗入一张0锤获得10肉，如果生产周期使用过任何捕猎的卡牌，则为0肉

## 捕猎类型
- 所有捕猎类型都有概率触发厄运事件, 风险可能不同

### 鹿
- 1锤7肉 => 1: 7

### 狼
- 2锤15肉 => 1:7.5

### 野猪
- 3锤20肉 ->  1 : 6

### 野牛 Bison
- 总共5锤40肉 -> 1:8
- 1锤 追踪，洗入一张围猎野牛
- 5锤获得野牛尸体，每个回合置入一张0锤10肉，持续4回合

- 又青铜器解锁武器装备，关系到军事线路

### 猛犸？？
- 需要或者和“军队的影响”有关系
