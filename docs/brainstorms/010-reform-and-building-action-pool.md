# 改革与建筑行动可选池

状态：改革三种操作与火塘示例已实现。

- 改革沿用 0 锤，每次打出完成以下一种操作后关闭，也可以放弃本次机会。
- 未知池固定抽取三个不同候选，三选一获得独立行动；同一次改革不能刷新候选。池内容在 `packages/core/src/content/reform-pool.json`。
- 未知池现有五张：搜寻食物、采集坚果、观察自然、组织劳作、节约口粮。
- 从可选池选择一张时，将该实体牌移入常驻卡组，可选池相应减少一张。
- 可以删除卡组中一张具体牌。常驻牌永久删除；自动周期牌通过排除该来源位置，避免下周期复原。
- 新增牌从下周期参与抽取；删除立即清理当前手牌和周期卡组，并调整抽牌位置，避免跳过未抽牌。
- 火塘建成只提供三张烧烤食物到可选池，不自动进入抽卡堆，不每周期重复补货。烧烤消耗 1 锤，将当前第一张食物价值提高 1；没有食物时不可打出。
- 建造火塘卡消耗 2 锤；已建成时禁止重复建造。可在自定义起始牌组配置，或用 `fire-pit-test` 开局直接带火塘。
- 建筑来源标记随卡从可选池进入卡组。建筑损坏移除其全部来源牌，包括可选池、常驻卡组、当前周期卡组及手牌，不影响其他来源的同名牌。
- 火塘供牌定义在 `content/buildings/fire-pit.json`。后续建筑可沿用这种建成供给可选池的规则。
- 开局浆果丛、部落中心目前保留自动周期供牌，作为已有开局规则的例外；是否把二者也改成必须改革选入，仍需明确。

Web 建筑区可模拟火塘损坏，用于检验来源清理。尚未设计危机自动损坏建筑的触发条件。
