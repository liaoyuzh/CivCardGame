# 游戏机制词条

状态：2026-09-06 已确认设计。本文记录机制定义，不表示运行代码已实现。

生产周期与食物模型以 [生产周期与食物收益基准](brainstorms/012-production-cycle-and-food-balance.md) 为准：默认每周期 3 回合，每回合基础 5 锤、抽 5 张牌，周期末统一结算食物与供养。

## 已确认词条

| 词条 | 效果定义 | 状态 |
| :---: | --- | :---: |
| 冒险 N | 效果结算后投六面骰，点数 ≤ N 时触发列出的后果。复制效果时重新投骰。 | 已确认 |
| 负伤 X | 下回合可用锤子减少 X，最低为 0，之后恢复。 | 已确认 |
| 取舍 X | 此卡结算后，随机弃掉其他手牌 X 张；不足则全部弃掉。 | 已确认 |
| 损毁 X | 向卡组加入 X 张「修整装备」：费用为 1 锤，无收益，具有「消耗」。抽到后需花锤打出以清除。 | 已确认 |
| 失机 X | 下回合基础抽牌数量减少 X，最低为 0；不影响卡牌额外抽牌。 | 已确认 |
| 收工 | 本回合不能再打出行动卡；玩家仍需主动结束回合。 | 已确认 |
| 消耗 | 此卡结算后永久移出卡组。 | 已确认 |
| 透支 X | 此卡收益结算后，本周期内后续每次食物产量减少 X，最低为 0。多次透支数值相加，周期结束时清除。 | 已确认 |

## 结算说明与设计意图

- 「修整装备」通过支付 1 锤打出并触发「消耗」永久移除；损毁会增加卡组负担，并占用抽牌机会与清理所需的劳动力。
- 「透支」对触发后的每次食物产量分别扣减，不是周期末食物总收益只扣一次；本卡收益不受本次新产生的透支影响，但仍受此前已生效的透支影响。
- 在本周期最后一次产粮时打出透支卡，可以避免本次透支造成后续产量损失。这是允许的时机收益，可与本周期留牌机制配合；具体留牌规则另行确定。
- 若当前周期获得额外回合，透支持续到实际周期结束。

## 按生产周期基准审核

- 劳动力与抽牌：普通周期基础预算为 15 锤、15 次抽牌机会。修整装备每张清理需 1 锤、无食物收益；卡组增加不会自动延长周期或增加锤子。失机 1 减少下回合 20% 的基础抽牌。
- 概率与时机：六面骰下，N 在 1 至 6 时冒险触发概率为 N/6；实际期望损失需结合列出的后果计算。取舍在其他手牌不足时损失较低，透支的损失取决于后续产粮次数与每次产量，不能只看最大惩罚。
- 食物与供养：具体卡牌仍须对照 1 锤约等于 1.5 食物的基准，并比较 5、10、15、20 人口的供养压力；本文未确定卡牌收益数值，不能据此认定具体卡牌已平衡。
- 组合：复制冒险效果需重新投骰；透支可叠加，留牌与出牌顺序可降低其实际代价。额外回合会延长透支的影响窗口，具体组合仍需随卡牌设计审核。
