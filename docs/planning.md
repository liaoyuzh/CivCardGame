# 卡池/卡堆
## 类型
- 手牌堆 
- 抽卡堆 (DrawPile)
- 弃牌堆 (DiscardPile)
- 卡组 (Deck)
- 卡组可选卡池 (DeckAvailablePool)
- 科研可选卡池 (ResearchAvailablePool)
- 贸易可选卡池 (TradeAvailablePool)


## 机制
- 每回合从抽卡堆抽x张置入手牌中
- 手牌堆有上线
- 打出的卡自动进入弃牌堆
- 抽卡堆在最后x张抽完之后不自动补充以抽满手牌
- “生产周期”(production cycle)：当回合结束且抽卡堆无卡牌时，复制卡组的卡牌并打乱洗满抽卡堆以进行新一轮的抽卡
- 有机制可以强行开启生产周期
- 可选卡池的概念在“改革”等板块详解


# 卡牌
## 资源卡
- 游戏最基本的代表资源的单元
- 通常不出现在手牌或者牌堆，卡池中
- 例子：5食物，6科研，7铁矿，10铀矿，12咖啡

### 基础资源卡
- 食物
- 产能：锤子
- 科研：瓶子
- 财富：金币

### 战略资源卡
- 独立于四种基础资源的资源单位
- 由特定的产能建筑产生
- 战略资源用于支付特殊卡牌所需的费用
- 大多数需要战略资源建造的卡牌都可以以亏损的比例消耗金币来打出
- 在市场中可以买到战略资源，也许也可以从科研中获取
- 例如：铁，铀

### 奢侈资源卡
- 很少能由产能建筑直接大规模生产
- 独立且稀有的机制类型
- 例如：茶叶

## 科技卡
- 需要在科研“商店”页面中用瓶子购买
- 大部分需要前置科技才可能出现在页面中

## 产出卡
- 获取资源/资源卡的方式
- 消耗锤子
- 偶尔消耗其他资源
- 例子：消耗2锤子获取5食物

## 建筑卡
- 解锁科技后相对应的建筑蓝图可以在科研或者市场界面购买
- 购买建筑蓝图后会洗入抽卡堆
- 花费锤子或特殊资源建造
- 建筑蓝图可能洗入多张，需全部完成才可建成

### 产能建筑
- 建成后提供被动加成，并加入相应的资源卡到可选卡池
- 例子：采石场
    - 被动：每回合被动获取1石头
    - 加入两张“采石”至可选卡池

### 奇观建筑
- 建成后一般为被动加成，更多为机制类型，少部分为一次性收益
- 例如：大灯塔，所有带有海洋探索标签所需的锤子消耗-1

## 事件卡
- 一般可产生特殊机制的卡牌
- 可能消耗资源
- 有主动打出的一般为正向收益机制的事件卡，例如：消耗2锤子，选择一张卡牌可在本回合末不进入弃牌堆
- 被动的，例如：在手牌中，每使用一张手牌则获得1瓶子
- 危机卡大多数为被动类型，危机卡机制具体在其他部分详解

# 游戏理念
- 游戏核心的推动理论
    - 社会物质生活条件决定了社会意识（意识形态） -> 生活消费品（资源）决定了意识形态 (抽象成危机, 例如封建时期和现代表现的社会危机不同)
    - 生产力决定了生活条件   -> 锤子换资源
    - 科学决定了生产力 -> 科技赋能到人口换锤子
- 因此有 科技换锤子，锤子换资源，资源引发危机从而变革，变革更需要新科技带动以解决新的问题，不断螺旋上升的文明发展进程

# 特殊机制/词条

## 生产周期
- 当回合结束且抽卡堆无卡牌时，复制卡组的卡牌并打乱洗满抽卡堆以进行新一轮的抽卡

## 改革
- 开局至少会有一张
- 卡组中有“改革”机制的卡可以进行以下动作：
    - 删除卡组的卡牌
    - 从可选卡池中选择x张加入卡组
    - 选择的卡从可选卡池中删除
    - 可选卡池中的卡一般从建筑获取，或者从科研/市场购买
- 保证整个游戏以“卡组构筑”为核心，且需玩家动态的根据时代和所面临的危机做调整
- 极端情况下会有允许玩家大面积删卡，置入卡牌的“改革”词条的机制卡存在
- 此极端情况下玩家有真空期带来的阵痛和虚弱感，突出时代进步必须大刀阔斧改革和百万漕工衣食所系之间的矛盾

## 科研
- 开局至少有一张
- 打出后进入科研“商店”界面
    - 界面提供总共x张卡牌
    - 每次购买卡牌默认不会在本次购物中补货
    - 不同卡牌按照对应的所需科研点数进行购买
    - 按一定数量的比例分配：
        - 至少有一定数量的科技卡
        - 至少有一定数量的建筑蓝图卡
        - 剩余的为事件卡
    - 提供的卡牌从“科研可选卡池”按概率表选取
    - 概率表由多方面共同决定
        - 流派
            - 种田多了，更多的会给相关的科技建筑或者机制卡
            - 科研多了，有极限概率给你抽跨时代科技卡牌
        - 地理位置：海洋更多给你海洋科技
        - 机制： 奇观或者事件机制卡会增加特定的卡牌刷新概率
- 科技卡买完即研发完这个科技，并解锁相对应后续科技，将相对应解锁的建筑蓝图置入科研可选卡池
- 建筑蓝图卡买完则置入x张蓝图（多为1）到卡组中（或者是抽卡堆？）
    - 如果是卡组的话，这张蓝图在第一次建造完成后不会再回到卡组而是消耗完毕
    - 如果是抽卡堆好处是卡组是干净的，坏处是你立刻研发这一轮就可以买到（是否是坏处取决于这样是否OP）
- 科技卡买完概率表中不会出现此科技
- 建筑蓝图卡出现了被购买，不会使得科研可选卡池去除此蓝图，即可重复刷到，其概率仍然又概率表决定


## 市场
- 开局至少有一张
- 打出后进入贸易“商店”界面
    - 界面提供总共x张卡牌
    - 每次购买卡牌默认不会在本次购物中补货
    - 不同卡牌按照对应的所需金钱进行购买
    - 按一定数量的比例分配：
        - 科技卡
        - 建筑蓝图
        - 建筑卡 （相当于直接购买，不需要蓝图）
        - 事件卡
        - 至少一定数量的资源卡，
            - 可以是基础资源，或战略资源，奢侈资源
            - 横向对比如果一些卡需要战略资源例如铁玩家没有则要以亏得比例用金币支付，这个比例在普通市场中交易的收益是要大得多的
            - 一些事件卡则会和他产生联动，例如下一次市场必定会带来一次交易铁的机会，玩家则可以来提前用优惠价格储蓄好以后所需要的关键资源

## 决策链条
- 此模式开启可能需要前置条件，并不是主流玩法 
- 主流玩法：可以一个个打出单张卡牌，卡牌在打出瞬间结算
- 此模式：开启后打出的卡牌并不是立刻结算，而是玩家深思熟虑后安排所有的卡牌形成决策链条然后在末尾按顺序结算
- 爽感上
    - 更爽的UI feedback
    - 音效feedback
- 打出的卡牌越多会有机制联动
    - 连续打出可以解锁伟人 或者形成个人的高级智库团 强化链条机制
    - 其他卡牌机制也可以强化例如连续打出五张卡第五张卡额外打出一次
- 回合结束按钮将会做成卡牌允许打出
- 若打出非本回合的即未来回合出现的卡牌，需要配合额外的可以看到抽卡堆牌序的机制才能链式
- 如果是打出类似需要指定卡牌，例如指定一张手牌如何如何，会调出界面可以搜索特定卡牌id，然后将其拖拽到链条中，在此期间的此操作都将默认为合法
- 在执行过程中不合法则中断，若此发生，则可能出现惩罚
- 任何有RNG生成之后需要做出的决策，玩家不能加入链条

## 偶然事件
- 每张打出的卡牌都有几率触发事件
- 事件可以是正向收益，也可以是危机（均为普通危机）
- 在打出时如果事件触发，卡牌则会翻置，然后显示出对应事件效果

## 时代
- 时代的进程根据难度会决定大致多少回合世界进入了这个时代（虽然没有其他对手国家的概念，但是属于是世界的平均水平）
- 世界进入了这个时代并不代表玩家的进程，玩家研究完本时代的所有科技，才代表完成了这个时代，进入了下一个时代
- 在完成这个时代后，会立刻开启这个时代的终极危机，详见终极危机

## 危机
## 普通危机
- 会出现在偶然事件中
- 每一次“生产周期”后，抽卡堆形成后，洗入一张
- 可能会有奖励？
- 会出现在科研或者贸易“商店”中，数量大多数一张，玩家可以购买

### 终极危机（金/红）
- 关底boss
- 基本在时代初期由系统决定
- 很鲜明的机制特点，大多数时候需要特定解法应对，通解行不通
- 玩家可以选择控时代的做法来延迟危机，但是不同的控时代的方式会有不一样的危机风险和收益
- 越早领先时代进入下一个时代意味着：
    - 更少的时间调整卡组应对下一个时代的挑战 （例如最开始只有粮食危机，到了下一个时代每回合开始有其他危机需要处理，如果你粮食屯的多，不会饿人口）
    - 更少的时间发展人口
    - 更少的时间积攒财富
    - 总结则是更少的发育时间
    - 相对应的减少boss难度，增加boss收益？
- 和世界进入下一个时代进行比较：
    - 若世界进入下一个时代前进入, 则当前危机最小，最大收益
    - 在世界进入下一个时代后有x回合，玩家可以选择
        - 若x回合内向下一个时代前进（算为同一时间进入）  正常危机和收益
        - 若x回合内未向下一个时代前进，任何x+n的回合，此危机会给人+n的相对应的难度提升，正常收益




## 稀有度
- 所有卡牌都可以设立一个稀有度
- 很大程度上决定了各种”商店“类型，”发现“类型的过程中概率表的主要因子
- 稀有度设计方向：
    - 白：数值期望值低，方差低, 少量极端冷门机制会搭配的卡，其中大多数是为了衬托红花而扮演的绿叶
    - 蓝：标准数值，对机制、卡牌体系没有决定性的影响
    - 金：数值期望值低，方差高，有独立影响机制、体系构筑的能力
    - 红：要么暴力数值美，要么独树一帜，开宗立派，要么两者皆有
